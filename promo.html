AIBK 한끼를 이용해 보세요. 메뉴가 잘 떠오르지 않는 분들을 위해 내 주변에 어떤 메뉴가 있는지를 먼저 보여주고, 거기서 거꾸로 가게를 찾아갑니다. 그래도 못 고르겠으면 「오늘 뭐 먹지?」에서 아무거나 뽑거나 사다리를 타세요.
지금 열기홈 화면에 추가하는 법
01
목적을 고르고
점심 · 카페 · 회식.
본점·파이낸스타워에서 걸어서 몇 분까지 갈지 정합니다.
02
메뉴를 둘러보고
한식 · 일식 · 중식 … 그 안의 칼국수 · 이자카야 · 양꼬치.
안 떠오르면 「오늘 뭐 먹지?」에서 뽑기·사다리.
03
가게로 들어갑니다
도보 시간, 인기 별점, 예약·룸·웨이팅,
전화 예약과 네이버 지도 길찾기까지 한 번에.
여러분의 성원에 힘입어 앱 버전으로 만들었습니다.
홈 화면에 추가하면 앱처럼 바로 열리고, 즐겨찾기가 유지되며, 오프라인에서도 열립니다.
  1. iPhone · Safari로 열기 → 아래 가운데 공유 버튼 → 홈 화면에 추가
  2. Android · Chrome → 오른쪽 위 ⋮ → 홈 화면에 추가 (삼성 인터넷: ≡ → 현재 페이지 추가 → 홈 화면)
  3. 카카오톡에서 열었다면 오른쪽 아래 ⋯ → 다른 브라우저로 열기 먼저
